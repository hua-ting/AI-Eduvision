# Markdown编辑器优化测试要点

## 1. 功能测试

### 1.1 展示层优化测试

- [ ] **样式统一测试**：验证所有Markdown文本（知识点详情、资料详情、问答内容等）的渲染样式是否统一
- [ ] **长文本渲染性能**：测试包含大量内容的Markdown文本是否能够流畅渲染，无明显卡顿
- [ ] **响应式适配**：在不同屏幕尺寸下（PC端）验证Markdown内容是否能正确适配
- [ ] **目录导航功能**：验证基于标题自动生成的目录是否正确，点击目录项能否跳转到对应位置
- [ ] **返回顶部功能**：验证返回顶部按钮是否正常工作

### 1.2 编辑层优化测试

- [ ] **工具栏功能**：验证所有编辑工具按钮（粗体、斜体、标题、代码块等）是否正常工作
- [ ] **自动保存功能**：验证在编辑过程中是否会自动保存草稿到本地存储
- [ ] **同步模式切换**：验证实时同步/手动同步模式切换是否正常
- [ ] **编辑器分屏**：验证编辑区和预览区的分屏显示是否正常
- [ ] **键盘快捷键**：验证常用快捷键（如Ctrl+S保存）是否正常工作

### 1.3 代码块专项测试

- [ ] **样式统一**：验证所有代码块的样式（边框、背景色、字体、行号）是否统一
- [ ] **语法高亮**：验证不同语言的代码是否能正确高亮显示
- [ ] **行号显示/隐藏**：验证是否可以切换行号的显示/隐藏
- [ ] **复制单个代码块**：验证单个代码块的复制功能
- [ ] **复制所有代码块**：验证复制页面中所有代码块的功能
- [ ] **代码块折叠**：验证大代码块的折叠/展开功能

### 1.4 权限逻辑兼容测试

- [ ] **申请进度展示**：验证用户提交的Markdown文本编辑申请状态是否正确显示
- [ ] **管理员对比视图**：验证管理员审核时是否能看到修改前后的对比
- [ ] **权限校验覆盖**：验证所有Markdown文本的编辑/保存/审核操作都经过权限校验

### 1.5 性能及其他测试

- [ ] **加载占位符**：验证Markdown内容加载时是否显示占位符
- [ ] **格式校验**：验证编辑时是否提供实时格式校验反馈
- [ ] **批量处理**：验证数据库批量操作是否正常工作

## 4. 边界情况测试

### 4.1 极端内容测试
- [ ] **超大文本**：测试包含超过10000字符的Markdown内容
- [ ] **嵌套复杂结构**：测试包含多层嵌套的列表、引用等复杂结构
- [ ] **特殊字符**：测试包含各种特殊字符和表情符号的内容
- [ ] **无效语法**：测试包含无效Markdown语法的内容处理

### 4.2 网络环境测试

- [ ] **断网重连**：测试网络中断后恢复的处理

## 5. 集成测试

### 5.1 与其他模块集成
- [ ] **知识点模块**：验证在知识点详情页使用Markdown渲染器是否正常
- [ ] **资料模块**：验证在资料详情页使用Markdown渲染器是否正常
- [ ] **问答模块**：验证在问答相关页面使用Markdown编辑器是否正常
- [ ] **贡献模块**：验证在知识点贡献页面使用Markdown编辑器是否正常

### 5.2 数据流测试
- [ ] **编辑→保存→显示**：验证从编辑到保存再到显示的完整流程
- [ ] **权限验证→操作→反馈**：验证权限验证和操作反馈的流程

## 6. 性能测试指标

### 6.1 渲染性能
- [ ] **首次渲染时间**：小文本(<1KB) < 100ms，中等文本(<10KB) < 300ms，大文本(<100KB) < 1s
- [ ] **滚动性能**：长文档滚动流畅，无卡顿
- [ ] **内存使用**：长时间使用后无明显内存泄漏

### 6.2 编辑性能
- [ ] **输入响应时间**：实时编辑时输入延迟 < 50ms
- [ ] **预览更新时间**：编辑后预览更新延迟 < 200ms
- [ ] **大文档编辑**：10000+字符文档编辑无明显卡顿

## 7. 安全性测试

- [ ] **XSS防护**：验证Markdown内容中不会执行恶意脚本
- [ ] **输入过滤**：验证对危险内容进行了适当的过滤和转义
- [ ] **权限控制**：验证只有授权用户可以执行编辑操作

## 8. 回归测试

- [ ] **原有功能**：确保优化不影响原有的核心功能
- [ ] **用户流程**：验证用户的主要使用流程不受影响
- [ ] **数据完整性**：确保优化过程中数据没有损坏或丢失
